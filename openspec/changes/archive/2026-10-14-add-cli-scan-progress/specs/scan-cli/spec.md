# Spec Delta

## MODIFIED Requirements

### Requirement: Формат результатов
Текст должен (SHALL) показывать IP, порт и состояние открытых портов сразу по мере получения наблюдений и итоговые счётчики всех исходов. Остальные пробы перечисляются только с `--verbose`. JSON должен (SHALL) быть одним корректным объектом с `results` и `summary`, строковыми IP с точками и строковыми состояниями. Диагностика должна (SHALL) направляться в stderr.

#### Scenario: Запрошен JSON
- **WHEN** пользователь запускает завершившееся сканирование с `--json`
- **THEN** stdout разбирается как один JSON-объект со всеми наблюдениями и сводкой
- **AND** stdout не содержит прогресс или диагностику
- **AND** stderr не содержит прогресс, в том числе с `--verbose`

#### Scenario: Компактные находки
- **WHEN** текстовое сканирование получает открытые и неуспешные пробы
- **THEN** открытые IP/порты печатаются до окончания сканирования ровно один раз
- **AND** закрытые порты, таймауты, недоступность и ошибки представлены в сводке без списка IP

#### Scenario: Подробности по запросу
- **WHEN** пользователь добавляет `--verbose` в текстовом режиме
- **THEN** вывод содержит каждую пробу с IP, портом и состоянием

#### Scenario: Нет находок
- **WHEN** завершённое сканирование не обнаружило открытых портов
- **THEN** CLI явно сообщает об отсутствии открытых портов и печатает счётчики
- **AND** не объявляет адреса отсутствующими в сети

## ADDED Requirements

### Requirement: Прогресс текстового поиска
CLI должен (SHALL) показывать в stderr начало, периодический прогресс и завершение текстового поиска: завершённые/все пары IP/порт, процент, число открытых портов и прошедшее время. Прогресс обновляется даже при ожидании проб. Терминал использует одну обновляемую строку; перенаправленный поток — редкие строки без управляющих последовательностей. `--no-progress` и `--json` должны (SHALL) отключать прогресс.

#### Scenario: Ожидание результатов
- **WHEN** текстовое сканирование длится более интервала обновления
- **THEN** прогресс виден до завершения даже если новые пробы ещё не завершились
- **AND** итоговый прогресс завершённого сканирования показывает все пары и 100 процентов

#### Scenario: Терминальный вывод
- **WHEN** stderr подключён к терминалу
- **THEN** прогресс обновляется в одной строке без повреждения строк находок
- **AND** при завершении или ошибке строка прогресса корректно заканчивается

#### Scenario: Перенаправление
- **WHEN** stderr перенаправлен в файл или канал
- **THEN** прогресс использует строки без ANSI-кодов и возврата каретки, не по строке на пробу

#### Scenario: Отключение прогресса
- **WHEN** передан `--no-progress`
- **THEN** stderr не содержит прогресс, а stdout сохраняет находки и сводку

### Requirement: Справка режимов поиска
Справка и README должны (SHALL) объяснять приоритет открытых портов, прогресс, `--verbose`, `--no-progress`, неизменный полный JSON и смысл таймаута. Повтор новых флагов должен (SHALL) отклоняться с кодом 2.

#### Scenario: Справка
- **WHEN** запрошен `--help`
- **THEN** перечислены новые флаги и компактное поведение по умолчанию

#### Scenario: Повтор флага
- **WHEN** `--verbose` или `--no-progress` указан дважды
- **THEN** CLI завершается с кодом 2 и диагностикой в stderr
