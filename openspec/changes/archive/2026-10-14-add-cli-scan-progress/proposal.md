# Proposal

## Why

CLI молчит до окончания поиска, затем печатает все пробы, включая многочисленные таймауты. Пользователю нужны видимый прогресс и немедленные находки, а подробности неуспешных проб — по запросу.

## What Changes

- Потоковый текстовый вывод открытых портов и понятная русская итоговая сводка.
- Прогресс в stderr: проверенные пары IP/порт, процент, открытые порты и прошедшее время; обновляемая строка в терминале и редкие строки при перенаправлении.
- **BREAKING**: текстовый режим по умолчанию больше не перечисляет неуспешные пробы; `--verbose` возвращает все наблюдения.
- `--no-progress` отключает прогресс; `--json` сохраняет полный прежний JSON без прогресса.
- Справка, README и локальные регрессионные тесты.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `scan-cli`: поток находок, компактные исходы и отображение прогресса.

## Impact

`src/trawler_cli.erl`, тесты CLI и README. Используются существующие `trawler:start_scan/3` и `trawler:status/1`; сетевое ядро, библиотечный API, лимиты, JSON и коды выхода не меняются. Без новых зависимостей, определения сервисов и утверждений об отсутствии хоста.
