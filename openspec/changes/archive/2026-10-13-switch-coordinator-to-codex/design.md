# Design

## Context

Hermes уже делегирует код и тесты Flash и хранит состояние проекта отдельно.
Установленная версия поддерживает `openai-codex` с транспортом `codex_responses`
и штатный импорт действующего входа Codex CLI в изолированное хранилище Hermes.
Мотивация описана в proposal.md.

## Goals / Non-Goals

**Goals:** сохранить автоматический цикл и привычный запуск, заменить координатора
на Sol medium, исключить расходы DeepSeek Pro и сохранить фоновое самообучение
в рамках лимитов ChatGPT.

**Non-Goals:** перенос в интерфейс Codex, изменение кода сканера, смена модели или
reasoning Flash, новые зависимости, перенос секретов и изменение глобальных настроек.

## Decisions

- В `.hermes/config.yaml` выбрать `model.provider: openai-codex`,
  `model.default: gpt-6.1-sol`, `model.api_mode: codex_responses` и
  `agent.reasoning_effort: medium`. Responses нужен для вызова инструментов Sol.
- Сохранить `delegation.provider: deepseek`, `delegation.model: deepseek-flash`,
  одного исполнителя, запрет вложенного делегирования и пустые цепочки fallback.
- Установить `auxiliary.background_review.enabled: true` без отдельного маршрута:
  фоновое самообучение наследует координатора Sol и расходует лимиты ChatGPT.
  Проверки результата координатором остаются частью обычного запроса.
- Использовать уже сохранённую авторизацию через штатный механизм Hermes.
  Для отдельного HERMES_HOME общий пользовательский профиль Hermes автоматически
  не наследуется; действующий вход Codex CLI импортируется штатным механизмом
  в игнорируемое локальное хранилище. Не копировать пользовательские конфигурации,
  `.env` и файлы авторизации целиком; не сохранять секреты в отслеживаемых файлах.
- Обновить роли в AGENTS.md и README. Указать, что лимиты ChatGPT и баланс Flash
  независимы. Исторические архивы сохраняют решения своего времени.

## Risks / Trade-offs

- [Сохранённый вход не доказывает доступ к конкретной модели] → отдельно проверять
  настройку и наличие входа без сетевых обращений; реальный доступ подтверждается
  успешным запросом при следующем запуске пользователя.
- [Лимит ChatGPT может закончиться] → сообщать ошибку; не включать платный fallback.
- [Flash продолжает расходовать API-баланс] → давать ему ограниченные задания и
  проверять фактический расход после изменений.

## Migration Plan

1. Валидировать изменение спецификации до применения конфигурации.
2. Поручить Flash только изменение исходного YAML; документацию обновляет координатор.
3. Проверить YAML, маршрут авторизации и независимость провайдеров без вызовов моделей.
4. Выполнить make check и архивировать изменение с обновлением текущей спецификации.
5. Новые настройки применяются при новом запуске `./scripts/hermes chat`.
