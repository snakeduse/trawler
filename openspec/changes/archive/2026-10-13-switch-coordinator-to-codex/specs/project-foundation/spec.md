## MODIFIED Requirements

### Requirement: Изолированное взаимодействие моделей
Обёртка Hermes должна (SHALL) выбирать `gpt-6.1-sol` с reasoning `medium`
через `openai-codex` координатором и `deepseek-flash` через `deepseek` исполнителем,
хранить состояние в игнорируемом runtime-каталоге и загружать навыки OpenSpec
проекта без изменения стандартного профиля Hermes. Автоматические обращения
`background_review` должны (SHALL) быть включены и наследовать модель координатора;
скрытый fallback запрещён.

#### Scenario: Запрос разработки запускает автоматический цикл
- **WHEN** пользователь запрашивает изменение поведения
- **THEN** Sol готовит и валидирует документы OpenSpec до делегирования Flash
- **AND** отдельная команда для Flash не требуется

#### Scenario: Запрошена только подготовка проекта
- **WHEN** пользователь запрашивает только каркас или спецификации
- **THEN** будущие задачи реализации остаются без отметок и не применяются автоматически

#### Scenario: Повторное использование существующего ключа
- **WHEN** ключ DeepSeek доступен в окружении процесса, runtime-файле env или пользовательском env Hermes
- **THEN** из этих файлов запускаемому процессу передаётся только этот ключ
- **AND** значение не печатается и не добавляется в отслеживаемую конфигурацию

#### Scenario: Подключение координатора через ChatGPT
- **WHEN** сохранённый вход ChatGPT доступен Hermes
- **THEN** координатор использует маршрут `openai-codex`, а не оплачиваемый по токенам OpenAI API
- **AND** секреты не копируются в отслеживаемые файлы проекта

#### Scenario: Отсутствие скрытой замены модели
- **WHEN** выбранный провайдер не может выполнить запрос из-за отсутствия входа или доступного лимита
- **THEN** ошибка сообщается пользователю без автоматического переключения на DeepSeek Pro или другой провайдер

#### Scenario: Фоновое самообучение через координатора
- **WHEN** основной запрос завершён и выполнены условия автоматического `background_review`
- **THEN** Hermes создаёт обращение для обновления памяти и навыков на модели координатора Sol
- **AND** это обращение использует маршрут ChatGPT, а не баланс API DeepSeek
