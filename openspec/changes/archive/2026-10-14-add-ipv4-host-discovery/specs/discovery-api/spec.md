# Spec Delta

## Purpose

Предоставить встраиваемый OTP API обнаружения IPv4-хостов с потоковыми результатами, синхронным сбором и управляемым жизненным циклом.

## ADDED Requirements

### Requirement: Публичный API обнаружения
Библиотека должна (SHALL) предоставлять `trawler:start_discovery/2`, `trawler:discover/2`, `trawler:discovery_status/1`, `trawler:cancel_discovery/1`. Адреса должны (SHALL) использовать существующие форматы и лимит `max_hosts`; все опции, методы и порты должны проверяться до отправки сетевых проб. При остановленном приложении возвращается `{error, not_started}`.

#### Scenario: Проверка входа
- **WHEN** адрес, метод, порт или опция неверны либо превышен лимит хостов
- **THEN** возвращается ошибка до отправки проб

#### Scenario: Приложение остановлено
- **WHEN** вызывается обнаружение без запущенного приложения
- **THEN** возвращается `{error, not_started}`

### Requirement: События и синхронный сбор
Асинхронный API должен (SHALL) посылать `{trawler_discovery, Ref, Event}` с результатами, предупреждениями и ровно одним завершающим событием. Синхронный API должен (SHALL) возвращать сортированные результаты и сводку с предупреждениями, сохранять чужие сообщения и не возвращать успешный частичный результат при deadline.

#### Scenario: Оба режима
- **WHEN** одинаковые loopback-запросы выполняются синхронно и асинхронно
- **THEN** результаты по адресам эквивалентны
- **AND** после завершения нет новых результатов, а чужие сообщения вызывающего сохранены

### Requirement: Supervision и очистка
Обнаружение должно (SHALL) выполняться под supervision. Отмена, deadline, ошибка, остановка приложения и выход владельца или получателя должны прекращать работу, закрывать сокеты, снимать мониторы и освобождать глобальную ёмкость до завершающего события. Завершённый статус должен (SHALL) храниться 60 секунд без полного списка результатов.

#### Scenario: Отмена и deadline
- **WHEN** обнаружение отменяется либо истекает deadline
- **THEN** ресурсы освобождены и отправлено одно событие cancelled либо error
- **AND** отмена уже отменённого задания идемпотентна

#### Scenario: Выход владельца и остановка
- **WHEN** владелец или получатель выходит либо приложение останавливается
- **THEN** активные воркеры и сокеты закрыты и ёмкость может использоваться другими заданиями

### Requirement: Состояние обнаружения
Статус должен (SHALL) содержать состояние, количество уникальных адресов, завершённых адресов и счётчики `up`, `no_response`, `error`. Неизвестные ссылки должны (SHALL) возвращать `{error, not_found}`, отмена завершённого задания — `{error, already_finished}`.

#### Scenario: Статус и неизвестная ссылка
- **WHEN** запрашивается действующая либо неизвестная ссылка обнаружения
- **THEN** возвращаются актуальные счётчики либо `{error, not_found}` соответственно
