# Spec Delta

## MODIFIED Requirements

### Requirement: Методы обнаружения
Обнаружение должно (SHALL) поддерживать `auto`, `arp`, `icmp`, `tcp` и `raw_tcp`. `tcp` использует connect к 80/443 либо явно выбранным портам; `icmp` использует echo и timestamp; `raw_tcp` использует SYN 443 и ACK 80. На Linux raw-методы должны (SHALL) работать без Nmap и собственного нативного helper. Явный TCP-набор допускает все номера 1..65535 и не ограничивается 16 портами.

#### Scenario: Полный набор удалённых проб
- **WHEN** выбран `auto` с доступными raw-методами для маршрутизируемого адреса
- **THEN** используются ICMP echo/timestamp, TCP SYN 443 и ACK 80
- **AND** подтверждение любым методом прекращает оставшуюся проверку адреса на доступность

#### Scenario: TCP без привилегий
- **WHEN** выбран `tcp` для loopback с открытым либо закрытым тестовым портом
- **THEN** успешное соединение или отказ подтверждает отвечающий адрес

#### Scenario: Большой явный TCP-набор
- **WHEN** пользователь задал более 16 корректных уникальных TCP-портов
- **THEN** набор принимается без молчаливой подмены и проверяется в конечном бюджете

### Requirement: Ограниченное ожидание и повторы
Ожидание должно (SHALL) использовать монотонное время, конечный срок на адрес, ограниченное число повторов и RTT-адаптацию с нижней/верхней границами. Число одновременно активных сетевых проб должно (SHALL) учитывать глобальный лимит вместе с TCP scan и индивидуальный лимит discover. Срок адреса должен включать маршрут, обнаружение и дополнительные проверки; исчерпание срока не должно отменять уже полученное подтверждение `up`.

#### Scenario: Потери и предел ожидания
- **WHEN** первая отправка не получила ответа
- **THEN** проба повторяется в пределах настроенного числа повторов и срока на адрес
- **AND** по истечении срока без подтверждения результат равен `no_response`, не утверждая отсутствия устройства

#### Scenario: Совместная нагрузка
- **WHEN** scan и discover выполняются одновременно
- **THEN** совокупные активные пробы не превышают глобальный лимит

#### Scenario: Дополнительные проверки после подтверждения
- **WHEN** адрес подтверждён, но срок заканчивается во время проверки портов или ОС
- **THEN** результат адреса остаётся `up`, непроверенные порты отмечены `skipped`, а предположение об ОС использует только полученные признаки
