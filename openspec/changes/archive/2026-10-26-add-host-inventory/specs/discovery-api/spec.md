# Spec Delta

## MODIFIED Requirements

### Requirement: Публичный API обнаружения
Библиотека должна (SHALL) предоставлять `trawler:start_discovery/2`, `trawler:discover/2`, `trawler:discovery_status/1`, `trawler:cancel_discovery/1`. Адреса должны (SHALL) использовать существующие форматы и лимит `max_hosts`; все опции, методы и порты должны проверяться до отправки сетевых проб. При остановленном приложении возвращается `{error, not_started}`. Опция `ports` допустима с любым методом, `os_detection` принимает только boolean и по умолчанию равна `false`.

#### Scenario: Проверка входа
- **WHEN** адрес, метод, порт или опция неверны либо превышен лимит хостов
- **THEN** возвращается ошибка до отправки проб

#### Scenario: Приложение остановлено
- **WHEN** вызывается обнаружение без запущенного приложения
- **THEN** возвращается `{error, not_started}`

#### Scenario: Порты при автоматическом методе
- **WHEN** переданы корректные `ports` с `auto` и `os_detection => true`
- **THEN** запрос принимается и дополнительные результаты включены в найденные адреса

## ADDED Requirements

### Requirement: Дополнительные поля результатов обнаружения

При явно заданных портах результат `up` должен (SHALL) содержать сортированные `port_results` и `open_ports`. При `os_detection => true` он должен содержать `os` с `family`, `confidence`, `evidence`. Синхронный и асинхронный API должны возвращать одинаковые дополнительные данные; число результатов и единица прогресса остаются адресами.

#### Scenario: Синхронный и потоковый сбор
- **WHEN** одинаковые запросы дополнительных проверок выполнены синхронно и асинхронно
- **THEN** дополнительные данные эквивалентны без учёта длительностей
- **AND** на адрес приходится ровно одно result-событие и одно увеличение completed

#### Scenario: Прежний запрос
- **WHEN** дополнительные порты не заданы и определение ОС выключено
- **THEN** дополнительные поля отсутствуют и сохраняется прежний контракт результатов
