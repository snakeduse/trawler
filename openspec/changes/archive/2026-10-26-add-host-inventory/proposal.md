# Proposal

## Why

Для системы развёртывания ПО нужен список отвечающих IP с необязательной приблизительной классификацией Windows/Linux, а не полный перебор популярных TCP-портов каждого адреса. Найденный адрес должен сохраняться даже при неизвестной ОС и закрытых или молчащих указанных портах.

## What Changes

- Расширить `discover`, сохранив все существующие форматы IPv4-целей и автоматический выбор метода обнаружения.
- Разрешить необязательные `ports` / `--ports` при любом методе: дополнительно проверять выбранные порты найденных адресов и возвращать их состояния; не использовать открытость порта как фильтр IP.
- Добавить отключаемую эвристическую классификацию ОС `os_detection => true` / `--os`: `windows`, `linux`, `unknown`, с качественным уровнем уверенности и основаниями. По умолчанию дополнительные OS-пробы выключены.
- Выполнять дополнительные проверки только после подтверждения адреса, последовательно внутри слота адреса и оставшегося общего бюджета `timeout_ms`. Возвращать явно непроверенные порты, не растягивая ожидание.
- Сохранить потоковый текст, прогресс по адресам, полный JSON, асинхронный API, отмену и глобальные ограничения ресурсов. `scan` не меняется.
- Обновить ограничения прежнего `discover --ports`: список больше не ограничен 16 портами; большой явно заданный список может не успеть провериться за бюджет адреса.

## Capabilities

### New Capabilities

- `host-inspection`: ограниченная проверка TCP-портов найденного адреса и необязательная эвристическая классификация ОС без авторизации.

### Modified Capabilities

- `host-discovery`: произвольный явно заданный TCP-набор в пределах допустимых номеров; общий бюджет адреса включает дополнительные проверки без потери подтверждения.
- `discovery-api`: новые опции и дополнительные поля результатов, валидация портов при любом методе.
- `discovery-cli`: дополнительные проверки `--ports` для всех методов, флаг `--os`, текст и JSON результатов.

## Impact

Затронуты `trawler_discovery`, `trawler_discovery_scan`, `trawler_discovery_probe`, `trawler_discovery_cli`, их тесты и документация; добавляется небольшой собственный модуль `trawler_host_inspection`. Внешние runtime-зависимости, Nmap, нативный helper, изменение firewall и capabilities не нужны. Не входят установка ПО, работа с учётными данными, подтверждение административных прав, IPv6, полная база fingerprints Nmap и гарантии обнаружения/распознавания всех устройств. Открытые порты дают только слабые признаки ОС; macOS, Samba, нестандартные сервисы и сетевые устройства могут приводить к ошибкам эвристики.
