# Выбор адресов и портов

## MODIFIED Requirements

### Requirement: Выбор портов
Сканер должен (SHALL) принимать отдельные TCP-порты, списки, включительные
диапазоны в пределах 1..65535 и специальное значение `default`,
устранять повторы и отклонять ноль или неверные границы диапазона.

#### Scenario: Смешанные порты
- **WHEN** вызывающий выбирает `22,80,80-82`
- **THEN** выбраны ровно порты 22, 80, 81 и 82

#### Scenario: Порты по умолчанию
- **WHEN** вызывающий передаёт `default` как выборку портов
- **THEN** выбраны порты набора по умолчанию (топ-1000)

## ADDED Requirements

### Requirement: Набор портов по умолчанию
Набор портов по умолчанию должен (SHALL) содержать ровно 1000 TCP-портов —
наиболее популярные порты частотного рейтинга `nmap-services` из дистрибутива
nmap. Он должен (SHALL) быть встроен в приложение как константа, без чтения
файлов nmap во время выполнения, и должен (SHALL) быть детерминированно
упорядочен по убыванию частоты.

#### Scenario: Размер и границы набора
- **WHEN** вызывающий запрашивает набор портов по умолчанию
- **THEN** возвращается ровно 1000 уникальных портов в пределах 1..65535

#### Scenario: Набор не зависит от nmap
- **WHEN** приложение работает без установленного nmap
- **THEN** набор портов по умолчанию доступен и не читает внешние файлы
