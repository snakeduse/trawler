# Проектирование портов по умолчанию

## Context

Порты сейчас обязательны: CLI требует `--ports`, а публичный API принимает
`ports_input()` без значения по умолчанию. См. proposal.md — Why.
`trawler_targets` разбирает и нормализует порты; `trawler_cli` — тонкий адаптер
публичного API; `trawler` — публичный API. Все сетевые тесты используют loopback.

## Goals / Non-Goals

**Goals:**

- Встроить в ядро набор из 1000 наиболее популярных TCP-портов.
- Сделать порты необязательными в CLI и публичном API через значение `default`.
- Сохранить обратную совместимость явных портов и не вводить новых зависимостей.

**Non-Goals:**

- Не читать `nmap-services` или иные файлы во время выполнения.
- Не добавлять настраиваемое число портов «топ-N» в CLI или API — только фиксированные 1000.
- Не менять порядок результатов, классификацию исходов и жизненный цикл сканирования.

## Decisions

### Набор портов и его происхождение

Новый модуль `trawler_ports` содержит встроенный константный список
`default/0` — 1000 портов частотного рейтинга `nmap-services` дистрибутива
nmap 7.95, отсортированных по убыванию частоты. Список генерируется один раз
при реализации и встраивается в исходный код как литерал; во время выполнения
не читаются внешние файлы и не требуется установленный nmap.

Альтернатива (читать `nmap-services` во время выполнения) отклонена: нарушает
требование встраиваемости и минимума зависимостей.

### Расширение типа портов

`trawler_targets:ports_input()` дополняется атомом `default`:

```erlang
-type ports_input() :: binary()
                     | [1..65535 | {range, 1..65535, 1..65535}]
                     | default.
```

`parse_ports(default)` возвращает `{ok, [{P, P} || P <- trawler_ports:default()]}`.
Разрешение `default` происходит в `parse_ports`, до любых сетевых операций,
как и остальная проверка ввода. Явно заданные порты разбираются как раньше.
Никаких новых процессов, сокетов или таймеров изменение не вводит.

### Публичный API

`trawler:scan/3` и `trawler:start_scan/3` сохраняют сигнатуру: оба уже принимают
`trawler_targets:ports_input()`, и после расширения типа `default` проходит
проверку. Обновляются только `@doc` и примеры модуля `trawler`; его код не меняется.

### CLI

`--ports` становится необязательным. При отсутствии ключа `do_scan` передаёт
в публичный API атом `default` вместо строки портов. Справка описывает набор
по умолчанию. Пропущенный `--ports` больше не считается ошибкой аргументов;
обязательным остаётся только `--targets`.

## Risks / Trade-offs

- Список 1000 портов зависит от версии `nmap-services` → зафиксировать версию
  7.991 и снабдить модуль комментарием о происхождении; тест проверяет инварианты
  (ровно 1000 уникальных портов в диапазоне 1..65535 и наличие якорных портов,
  например 80 и 443).
- Сканирование по умолчанию создаёт до 1000 проб на хост → ограничивается
  существующими лимитами параллелизма; дополнительных лимитов не требуется.
- Проверка `default` в CLI без `--ports` на loopback затрагивает 1000 портов →
  тесты используют закрытые порты loopback (быстрый `econnrefused`) и не
  полагаются на случайные задержки.
