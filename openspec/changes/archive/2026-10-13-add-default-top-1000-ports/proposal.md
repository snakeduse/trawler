# Порты по умолчанию: топ-1000 nmap

## Why

Сейчас порты обязательны и в CLI (`--ports`), и в публичном Erlang API.
Пользователю часто не важно, какие именно порты проверять, — нужен разумный
набор по умолчанию, как у nmap. Делаем указание портов необязательным:
при отсутствии явных портов сканер проверяет 1000 наиболее популярных портов.

## What Changes

- Добавить в ядро модуль `trawler_ports` со встроенным константным списком
  1000 наиболее популярных TCP-портов в порядке частотного рейтинга
  `nmap-services` из дистрибутива nmap (без зависимости от установленного nmap).
- Сделать порты необязательными в библиотеке: тип `ports_input()` принимает
  атом `default`, а `parse_ports(default)` возвращает нормализованный список
  портов по умолчанию.
- Сделать `--ports` необязательным в CLI: при отсутствии ключа используется
  набор портов по умолчанию; справка отражает новое поведение.
- Публичный API `scan/3` и `start_scan/3` принимает `default` как значение портов.
- Расширить проверки разбора, тесты ядра и CLI на поведение по умолчанию.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `target-selection`: порты по умолчанию и приём `default` как входной выборки портов.
- `scan-cli`: `--ports` необязателен, при отсутствии используется набор по умолчанию.

## Impact

Новый модуль `trawler_ports`; изменяются `trawler_targets` (разбор портов и тип),
`trawler` (документация и тип портов) и `trawler_cli` (разбор аргументов и справка).
Зависимости во время выполнения не меняются: список портов встроен в код
как константа, полученная из частотного рейтинга `nmap-services`.
Явно указанные порты ведут себя как раньше — изменение обратно совместимо.
Сетевые тесты остаются на loopback и локальных тестовых сокетах.
